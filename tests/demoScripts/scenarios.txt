19. Verify Sorting
Question:
“Sort products by price and verify that prices are in ascending order.”

Conceptually:

const prices = await page.locator('.product-price').allTextContents();

const numericPrices = prices.map(price =>
  Number(price.replace(/[₹,]/g, ''))
);

const sortedPrices = [...numericPrices].sort((a, b) => a - b);

expect(numericPrices).toEqual(sortedPrices);

This is an excellent interview coding problem because it combines Playwright + TypeScript + JavaScript.

32. Login Once and Reuse Session
Question:
“How would you avoid logging in before every test?”

Use Playwright's storage state.

await context.storageState({
  path: 'auth.json'
});

Then configure:

use: {
  storageState: 'auth.json'
}

35. Page Object Model
Question:
“Convert the login test into Page Object Model.”

export class LoginPage {
  constructor(private page: Page) {}

  username = this.page.getByLabel('Username');
  password = this.page.getByLabel('Password');
  loginButton = this.page.getByRole('button', { name: 'Login' });

  async login(username: string, password: string) {
    await this.username.fill(username);
    await this.password.fill(password);
    await this.loginButton.click();
  }
}

39. Scroll and Click
Question:
“Find an element at the bottom of the page and click it.”

Usually Playwright handles scrolling automatically:

await page.getByText('Customer Service').click();

You can explicitly scroll when needed:

await page.getByText('Customer Service').scrollIntoViewIfNeeded();
await page.getByText('Customer Service').click();

40. The Classic Interview Challenge
A very realistic combined question is:

“Open Amazon. Get all header menu items from Fresh through Customer Service. Iterate through them, click each one, verify the expected page/URL, and return to the homepage before clicking the next item.”

A clean approach:

const menuItems = [
  'Fresh',
  'Amazon MiniTV',
  'Sell',
  'Best Sellers',
  'Mobiles',
  'Today\'s Deals',
  'Customer Service'
];

for (const item of menuItems) {
  await page.getByText(item, { exact: true }).click();

  // Verify navigation
  await expect(page).toHaveURL(/amazon/);

  // Return to home
  await page.goto('https://www.amazon.in/');
}

But an experienced interviewer may intentionally reject this solution and ask:

“Why are you hardcoding the menu names?”

Then you'd improve it by reading the menu elements dynamically from the DOM:

const menuItems = page.locator('#nav-xshop a');

const count = await menuItems.count();

for (let i = 0; i < count; i++) {
  const item = menuItems.nth(i);

  console.log(await item.innerText());

  await item.click();

  await page.goBack();
}
